Gemini API 키 발급 방법

1. Google AI Studio 접속 및 로그인

  • Google AI Studio 웹사이트에 접속합니다. 🔗 [바로가기]
  • Google 계정으로 로그인합니다.

2. API Key 생성 페이지 이동

  • 로그인 후 화면 좌측 사이드 메뉴 또는 메인 화면에서 Get API key (또는 Create API key) 버튼을 클릭합니다.

3. API Key 발급

  • Create API key 버튼을 누릅니다.
  • 연결할 Google Cloud 프로젝트를 선택하거나, 새로운 프로젝트를 생성하여 진행합니다.
  • 생성 버튼을 누르면 AIza...로 시작하는 키 문자열이 즉시 발급됩니다.
